HOW TO ADD REAL FACES + REAL LOGOS
==================================

The game draws cartoon players/baseballs by default. To use real photos,
just drop image files in here with the exact names below. Refresh the page
and they appear automatically. Any file you don't add stays cartoon.

Best results: square-ish PNG, transparent or plain background, ~200x200px.

PLAYER FACES  ->  img/players/<name>.png
  acuna.png      Ronald Acuna Jr.
  harper.png     Bryce Harper
  ohtani.png     Shohei Ohtani
  judge.png      Aaron Judge
  betts.png      Mookie Betts
  trout.png      Mike Trout
  soto.png       Juan Soto
  freeman.png    Freddie Freeman
  vladjr.png     Vladimir Guerrero Jr.
  tatis.png      Fernando Tatis Jr.
  jramirez.png   Jose Ramirez
  seager.png     Corey Seager

TEAM LOGOS (on the baseballs)  ->  img/logos/<abbr>.png
  nym.png  phi.png  mia.png  wsh.png  lad.png
  hou.png  sd.png   nyy.png  atl.png

Tip: Google "<team> logo png" or "<player> face png", save into the
right folder with the filename above. That's it.
