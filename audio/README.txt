REAL STADIUM SOUNDS (V3)
========================
Drop short audio clips here (mp3 works best) with these EXACT names.
Refresh the game and they play automatically. No file = soft synth fallback,
and there is NO robot voice anymore.

  playball.mp3   plays once when a game starts ("Play ball!" announcer)
  crowd.mp3      loops as background stadium ambiance (keep it 10-30s, it loops)
  hit.mp3        crack of the bat -- plays on every jump
  cheer.mp3      crowd cheer -- plays on each level-up
  out.mp3        groan/"aww" -- plays when you strike out

Tip: rip short clips from YouTube (a bat crack, a crowd loop, an umpire
"play ball"), convert to mp3, name them as above, drop them in this folder.
Keep them SHORT so they load fast on the phone.
